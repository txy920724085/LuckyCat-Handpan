## 二、安装

1. 将 `01_安装包/HandpanPractice-v0.9.apk` 发送到 Android 手机；
2. 允许“安装未知应用”，点击安装；
3. 若手机装过旧版本（v0.4–v0.8，同签名），可直接覆盖，数据保留；
4. 打开后授予蓝牙权限（Android 12+），在系统蓝牙中先配对 `JDY-31`。

> 安装包使用开发证书（`keystore/development.keystore`，口令 `android`），仅用于测试与评审；正式发布请替换正式证书。

## 三、源码与构建

源码为 **非 Gradle 的轻量构建**（javac + d8 + aapt2 + zipalign + apksigner），便于在无 Android Studio 的环境复现。

```bat
cd 02_源码
build.bat
```

需要 JDK 17+、Python 3、Android build-tools 34、platform 35 的 `android.jar`、R8 9.5.28。工具不随包提交，下载与放置方式见 `02_源码/构建说明.md`。

源码结构：


## 五、快速体验

1. **节拍器**：底部「节拍」→ 选择音色（铃+木 / 机械单击）→ 启动；可切 4/4、3/4、2/4。
2. **曲谱**：底部「跟练」→ 曲谱库 → 导入 `04_附件/示例曲谱/*.json`；选中后速度自动切到该曲 BPM。
3. **蓝牙跟练**：连接 JDY-31 后，示范/跟练会把音符发到实体手碟，并显示真实敲击与命中。

## 六、说明

- 本作品是在既有 v0.4 功能基础上完成界面重做、节拍器音色、曲谱时序与休止/留白支持；
- 蓝牙实体链路（JDY-31 / QSU1 / HTE1）未在提交环境中联调，协议代码保持原样；
- 受 FPGA 固件限制（无 note-off），单个音符的音频尾长由硬件决定，APP 通过谱面时值与留白表达长短，详见《软件说明书》第 8 节。

公开仓库不提供私钥文件；构建脚本会在本地生成开发测试证书。重新生成证书后通常不能直接覆盖原证书签名的安装包，应卸载旧版或使用自己保管的同一密钥。发布应用请使用自行保管的正式证书。
