# 构建说明

本项目不是 Gradle 工程，而是 **javac + d8(R8) + aapt2 + zipalign + apksigner** 的轻量构建流程，目的是在没有 Android Studio 的环境里也能复现安装包。

## 1. 环境要求

| 组件 | 版本 | 用途 |
|---|---|---|
| JDK | 17 及以上（本项目在 JDK 25 上构建） | javac / jar / java |
| Python | 3.8+ | `pack.py` 打包 |
| Android build-tools | 34（或 33+） | aapt2 / zipalign / apksigner |
| Android platform | API 35 `android.jar` | 编译与 d8 的 classpath |
| R8 | 9.5.28 | d8 生成 dex |

## 2. 目录准备

在 `02_源码/` 下建立：

```
tools/
├── android-14/          # build-tools 34 解压后的内容（含 aapt2.exe、zipalign.exe、apksigner.bat、lib/）
├── android-35/
│   └── android.jar      # API 35 平台
└── r8.jar               # R8 9.5.28
```

下载地址：

- build-tools 34：<https://dl.google.com/android/repository/build-tools_r34-windows.zip>
- platform 35：<https://dl.google.com/android/repository/platform-35_r02.zip>（解压后取 `android-35/android.jar`）
- R8 9.5.28：<https://dl.google.com/dl/android/maven2/com/android/tools/r8/9.5.28/r8-9.5.28.jar>

也可以把 tools 放在别处，运行时指定：

```bat
set HP_TOOLS=D:\android-tools
build.bat
```

## 3. 构建

```bat
cd 02_源码
build.bat
```

产物：`out/HandpanPractice-v0.9.apk`。

流程：

1. `javac --release 11` 编译 5 个 Java 文件；
2. `jar` 打包 classes，`d8` 生成 `classes.dex`；
3. `aapt2 compile` 资源，`aapt2 link` 生成 base.apk（WAV 用 `-0 wav` 保持不压缩，供 SoundPool 使用）；
4. `pack.py` 把 `classes.dex` 写入 APK，并保持 `resources.arsc` 与 `res/raw/*.wav` 不压缩；
5. `zipalign -p 4` 对齐；
6. `apksigner` 签名（v1+v2+v3）。

## 4. 签名

使用 `keystore/development.keystore`：

- 别名：`androiddebugkey`
- 库口令 / 密钥口令：`android`

仓库不含签名私钥；build.bat会在本地生成开发测试证书。新证书通常不能直接覆盖原签名安装包。正式发布请使用自己保管的正式证书。

## 5. 常见问题

| 现象 | 处理 |
|---|---|
| `javac` 找不到 | 安装 JDK 17+，把 `bin` 加入 PATH |
| `aapt2` 报无法打开 res | 在 `app/` 目录内以相对路径 `res` 编译（脚本已这样处理） |
| emulator/手机提示解析失败 | 确认 `resources.arsc` 未压缩且 4 字节对齐（`zipalign -c -v 4` 检查） |
| 安装提示签名冲突 | 先卸载旧版本；或使用同一 keystore 重新签名 |
