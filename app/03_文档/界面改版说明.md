## 9. v0.5.1：安装失败（安装器闪退）修复

### 现象

v0.5 在 MuMu（Android 15）可正常安装运行，但在真机上“安装过程中闪退 / 无法安装”。

### 根因

**签名不一致。** v0.5 使用本次新建的 `_build/release.keystore`（CN=Handpan Practice，SHA-256 `42005797…`），而手机上此前的 v0.4 是用 `local-build/development.keystore` 签的（CN=Handpan Development，SHA-256 `b4916142…79c4c3`）。

Android 不允许用不同证书覆盖同包名应用，安装器在“替换安装”阶段会直接失败；部分国产 ROM 的安装器在此场景下会异常退出，表现就是“闪退、装不上”。

已核对：`keytool -list -v -keystore local-build/development.keystore -storepass android` 输出的 SHA-256 与原 v0.4 的签名证书**逐位一致**（别名 `androiddebugkey`，口令 `android`）。

在模拟器上复现，报错原文：

```
INSTALL_FAILED_UPDATE_INCOMPATIBLE: Existing package cn.handpan.practice
signatures do not match newer version; ignoring!
```

换成同一证书后覆盖安装直接 `Success`。

### 修复

1. 改用 `local-build/development.keystore` 签名，证书与原 v0.4 完全一致；
2. `versionCode 5 → 6`、`versionName 0.5 → 0.5.1`，保证是“升级”而不是降级；
3. 其他兼容性加固：
   - `uses-feature android.hardware.bluetooth` 改为 `required="false"`（避免无蓝牙设备/部分平板被判不兼容）；
   - `getSystemService(BluetoothManager.class)` 改为 `getSystemService(Context.BLUETOOTH_SERVICE)`（前者 API 23 才有，minSdk 21 时点击连接会 `NoSuchMethodError`）；
   - `ToneGenerator` 构造加异常保护，音频初始化失败不再导致启动崩溃；
   - 保留 v1+v2+v3 签名、`resources.arsc` 未压缩 + 4 字节对齐、minSdk 21、无 native 库。

### 验证

| 步骤 | 结果 |
|---|---|
| 先安装原 v0.4（dev 证书） | Success |
| 直接 `install -r` v0.5.1（不卸载） | **Success**（签名一致，覆盖升级） |
| 启动 | 正常，`logcat -s AndroidRuntime:E` 无 FATAL |
| 版本 | versionCode 6 / versionName 0.5.1 |

截图：`dist/screens/06_安装升级后.png`

### 如果真机仍失败

按 `dist/安装说明.txt` 操作：先卸载旧版再装、确认文件 SHA-256、避免用微信直接打开。仍不行则需要手机型号/Android 版本/错误原文或 `adb logcat -d -s AndroidRuntime:E`，才能区分“安装器解析问题”还是“运行期崩溃”。

> v0.5 安装包已撤下，`dist/` 只保留 v0.5.1。

## 10. v0.6：节拍器真实音色 + 两个 BUG 修复

versionCode 7 / versionName 0.6，仍使用原开发证书，可直接覆盖 v0.2–v0.5.1。

### 10.1 节拍器音色（两套，用户自选）

| 预设 | 重拍 | 弱拍 | 说明 |
|---|---|---|---|
| 铃 + 木（默认） | `metro_bell.wav` | `metro_wood.wav` | 塑料铃 + 木质节拍器，强弱分明 |
| 机械单击 | `metro_click.wav` | `metro_click.wav` | 真实机械节拍器单击，弱拍音量 0.72 |

实现：

- 音频放在 `res/raw/`，44.1kHz / 单声道 / 16-bit；
- 用 `SoundPool`（`USAGE_MEDIA` + `CONTENT_TYPE_SONIFICATION`，maxStreams 4）预加载，替代原来的 `ToneGenerator` beep；
- `res/raw` 的 WAV 在 APK 内保持 **未压缩**（aapt2 `-0 wav` + pack.py 保留压缩策略），否则 `openRawResourceFd` 会失败；
- 选择写入 `SharedPreferences("metro_preset")`，重启保留；
- 若样本尚未加载完成，自动回退到 `ToneGenerator`，不会静音。

界面：节拍器卡片新增「音色」分段控件（铃 + 木 / 机械单击），位于拍号上方。

### 10.2 BUG 1：切换拍号后按钮文案不更新

原逻辑：点拍号 → `metro = false`，但没有同步底部按钮和节拍文字，于是出现“已停止但按钮还写停止节拍”。

修复：切拍号时若正在运行，同时把 `beatText` 置为「已停止」、按钮文案置为「启动节拍」；调 BPM 时也做同样处理。

### 10.3 BUG 2：连续同音看不出是两拍

原因：手碟示意图的高亮只取决于“当前拍对应的音位”，连续两拍同一个音时高亮连续不灭，看起来像一次长按。

修复：在 `Pad.onDraw()` 里，若当前音与下一拍音相同，则在**本拍最后 18%**（`phase >= 0.82`）临时关闭该音位高亮，形成一个极短的“空帧”，下一拍再亮起——视觉上就是清晰的两次闪烁。不同音高时不受影响。

## 11. v0.7：曲谱休止 + 切换音色状态修复

versionCode 8 / versionName 0.7，仍为原开发证书，可直接覆盖。

### 11.1 导入曲谱支持「休止」

问题：格式是“每拍一个音”，导入的曲子连续不断，听起来像机器在吐音符。

扩展：`positions` 允许 **0**，表示该拍休止（不发声）。

- 校验：`0–8`（0=休止，1–8=音位）；
- 播放：`tick` 里遇到 `song[n] < 0` 直接跳过，不发送 MIDI 音符；
- 谱面：休止显示为 `·`（浅灰），不再显示 0；
- 命中：休止不计入命中总数（结算显示 `命中 x / 有效音符数`）；
- 手碟示意图：休止拍不高亮，`PositionMap.channel(-1)` 不会越界。

内置曲谱与旧曲谱不受影响（旧数据没有 0）。

配套重新生成了 14 首「呼吸版」曲谱（`音频素材/02_曲谱/json_含休止/`），标题带「· 呼吸版」后缀，可与旧曲谱并存导入。

### 11.2 切换节拍器音色：停止 + 同步按钮

与拍号一致：运行中切换「铃+木 / 机械单击」会停止节拍、显示「已停止」、按钮变回「启动节拍」，不再出现“已停但按钮还写停止”的状态。

## 12. v0.8：演示 / 跟练时序重写（每首歌自带速度 + 每个音的时值不同）

versionCode 9 / versionName 0.8。

### 12.1 问题

原实现是「每拍一个音」：`positions` 长度为拍数，`tick` 按 BPM 每拍发一个音。
所以导入的曲子听起来像机器连续吐音符，音符之间没有长短变化。

### 12.2 新数据模型

新增 `Song` / `Song.Note`：

```java
class Note { float start; float dur; int pos; }   // 拍为单位；pos=-1 休止
class Song { String title; float bpm; Note[] notes; float length; int hitCount; }
```

- 每首曲子有自己的 `bpm`（40–200），选中曲谱后自动写入速度滑杆；
- 每个音符有独立 `start` 与 `dur`，两个音之间的空档 = `next.start - (start + dur)`，可长可短；
- 兼容旧格式：`version=1` 的 `positions` 会转成“1 拍/音、85 BPM”的 `Song`。

导入格式（v2）：

```json
{"version":2,"beats_per_bar":4,"title":"…","bpm":96,
 "notes":[{"b":0.0,"d":0.5,"p":5},{"b":1.0,"d":0.75,"p":5}]}
```

### 12.3 播放 / 跟练 / 展示

| 环节 | 行为 |
|---|---|
| 演示 | `tick` 按 `beatPos` 推进，只有到达 `note.start` 才发送；空档期间不发送，形成停顿；迟到超过 0.35 拍的音符直接跳过，不补发 |
| 跟练 | 判定改为“找最近一个未命中、音位匹配、起点在 ±250ms 内的音符”，不再假设每拍一个音 |
| 手碟示意图 | 高亮跟随 `noteAt(beatPos)`：音符时值多长就亮多久，空档自然熄灭 |
| 谱面 | 按真实时值绘制：横向位置 = 起点，块宽 = 时长，块与块之间的空白就是停顿；播放头连续移动 |
| 速度 | 选中曲谱时读取 `song.bpm`，滑杆与「xx BPM」同步；仍可手动改速度练习 |
| 结算 | 分母为 `hitCount`（不含休止） |
